# Visionix AI

Visionix AI is a futuristic AI powered OCR browser extension that allows users to instantly extract text from anywhere on their screen. From code snippets and scanned documents to PDFs, charts, images, and video frames, Visionix AI converts visual content into editable text within seconds using an immersive browser based OCR experience.

✨ Features

- 🔍 Interactive OCR browser simulator
- ✂️ Drag and capture screen selection
- ⚡ Realistic OCR processing animations
- 🎨 Premium glassmorphism UI design
- 🌙 Dark and light theme support
- 📱 Fully responsive layout
- 📂 Export options for PDF, TXT, and DOCX
- 🕘 Capture history management
- 🚀 Smooth transitions and modern animations
- 🧠 Tesseract.js inspired OCR workflow
- 💻 Modern JavaScript architecture
